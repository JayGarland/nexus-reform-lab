# L-0662 RESULT: ControlPlaneDispatch Indirection + Audit Log Delivered (Phase 2 Narrow Slice)

## Conclusion

Delivered exactly the narrow slice this letter scoped: `core/dispatch.go`'s `maybeHandleDispatchBlock` no longer calls `executeDispatch` directly — it calls the new `Engine.ControlPlaneDispatch` (`core/controlplane.go`), which wraps `executeDispatch`'s existing logic byte-for-byte and additionally appends one entry to a new `control_plane_audit.json` log (`core/controlplane_audit.go`) per dispatch attempt, success or failure. Session-lifecycle call sites (`resetSessionForTurn`, `cmdNew`, `cmdSwitch`) were **not** touched, as scoped — deferred to Phase 2b. On `F:\foundry\worktrees\cc-connect-L-0662`, branch `architect/L-0662-controlplane-dispatch`, commit `21417cdd`, unpushed.

## What was built

- `core/controlplane.go`: `Engine.ControlPlaneDispatch(p, sourceSessionKey, req)` — calls `e.executeDispatch(...)` unchanged, then `recordControlPlaneDispatch` regardless of outcome.
- `core/controlplane_audit.go`: `ControlPlaneAuditEntry` + `controlPlaneAuditStore`, same atomic-write/mutex-guarded JSON shape as `dispatchStore` (`core/dispatch.go:119-236`).
- `core/dispatch.go:498`: one-line change — `e.executeDispatch(...)` → `e.ControlPlaneDispatch(...)` inside `maybeHandleDispatchBlock`. This is the entire behavioral surface of the change; `executeDispatch` itself is untouched.
- `core/engine.go`: one new struct field (`controlPlaneAudit *controlPlaneAuditStore`), no other changes.
- `core/controlplane_test.go`: `TestControlPlaneDispatch_RecordsAuditEntryAndPreservesBehavior` reruns the exact scenario from the pre-existing `TestExecuteDispatchFallback` (`core/dispatch_test.go:245`) through the new wrapper and asserts both (a) the pre-existing effects — receipt text, dispatch ledger entry — are byte-for-byte unchanged, and (b) exactly one audit entry is recorded with the right fields. `TestControlPlaneDispatch_RecordsAuditEntryOnFailure` confirms a rejected dispatch (unknown target seat) is also recorded, with a non-`"ok"` outcome — the audit log records attempts, not just successes.

# Concept and Contract Expansion Freeze

> **Status**: `ACTIVE GOVERNANCE BOUNDARY — OUTSIDE AUTHORIZED`
> **Purpose**: Stop horizontal expansion of Concept Models, Minimum Contracts, state machines, future components, and topology layers, and redirect effort to real Prior-Art Probe verification, unless a real Probe exposes a blocking contradiction or a clear safety hole.
> **Scope**: Governance boundary. This freeze does not delete existing models or Contracts, does not authorize implementation, and does not by itself run any Probe.
> **Basis**: [`FOUR_LAYER_ONE_WORLD_MINIMUM_LANDING_ROADMAP.md`](../plans/FOUR_LAYER_ONE_WORLD_MINIMUM_LANDING_ROADMAP.md) (`CONFIRMED FOR ROADMAP SCOPE`), [`GLOBAL_ROADMAP_RECONCILIATION.md`](../plans/GLOBAL_ROADMAP_RECONCILIATION.md) (`ROADMAP RECONCILIATION — UNDER OUTSIDE REVIEW`), [`CONTRACT_TO_PROBE_MATRIX.md`](../probes/CONTRACT_TO_PROBE_MATRIX.md) (`PROBE MATRIX — UNDER OUTSIDE REVIEW`)

---

## 1. Core Rule

> 从本轮开始，不再新增横向 Concept Model、Minimum Contract、状态机、未来组件或拓扑层级，除非真实 Prior-Art Probe 暴露出阻断性矛盾或明确安全漏洞。

## 2. Frozen Objects

The following MUST NOT be expanded horizontally:

```text
new World / Scope / Room conceptual layers
new Session or Attempt states
new Protocol lifecycle states
new Evaluation object families
new Runtime classifications
new theoretical Providers
new broad architecture models
```

This includes new Minimum Contracts, new state machines, new object families, and new future-component descriptions.

## 3. Thaw Conditions

The freeze may be lifted ONLY when:

1. a real Probe cannot execute, and the reason comes from a missing Contract;
2. two already confirmed Contracts directly contradict each other;
3. real wheel behavior proves an existing semantic is wrong;
4. a clear safety or irreversible risk is not covered;
5. box-outside explicitly approves the thaw.

A box-in AI MUST NOT lift the freeze by itself.

## 4. Existing Artifacts

Existing models and Contracts are retained, but MUST be described as:

```text
semantic hypotheses
acceptance requirements
risk checklist
probe questions
```

They MUST NOT be described as already-running or already-real-world-verified systems.

## 5. Relation to Probes

The freeze does not block Probe planning, Prior-Art Candidate Refresh, or real wheel investigation. It blocks the production of more unverified horizontal design.

## 6. Non-Implementation

This freeze does not authorize:

- implementing any Engine or Runtime
- running any real Probe
- selecting or binding any Provider
- connecting the official Nexus
- starting CR-S0

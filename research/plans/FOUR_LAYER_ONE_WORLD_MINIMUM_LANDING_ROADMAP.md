# Four-Layer One-World Minimum Landing Roadmap

> **Status**: `ROADMAP — UNDER OUTSIDE REVIEW`
> **Purpose**: Answer, at the global level: without connecting the official Nexus, what minimum runnable capabilities does the Four-Layer One-World still lack, and what threshold must be reached before entering Nexus Shadow Integration.
> **Prohibition**: This roadmap does NOT authorize any Probe, Provider selection, or Nexus connection.

## Capability State Model

Every capability is marked with exactly one of:

```text
CONCEPT DEFINED
MINIMUM MECHANISM PROVEN
READY FOR SHADOW INTEGRATION
```

No vague "landed/done" wording is used.

---

## A. Persistent Artifact World / Runtime & Re-entry

Current state: `Level 2 — Recoverable Persistent Artifact World`.

Completed: WAKE / HELLO; state pointers; Git lineage; fresh-instance recovery; external verdict; fail-closed verifier.

Still missing minimum capabilities:

```text
bounded executable Work Item
single-run claim / lease
interrupted-run recovery
stale claim handling
explicit completion / review handoff
no autonomous infinite loop
```

Status: `CONCEPT DEFINED` (Level 2 recoverability proven; bounded execution runtime not implemented).

---

## B. Knowledge Projection

Current state: `Two E3-capable candidates confirmed; Provider not selected`.

Next threshold is NOT more candidate search; it is a future E4:

```text
identical Nexus-compatible fixture
incremental update
provenance
information-loss review
export / rollback
outside comparison
```

E4 is NOT authorized at this time.

Status: `MINIMUM MECHANISM PROVEN` (two candidates at E3 scope; no E4, no selection).

---

## C. Stigmergy / Coordination

Current state: `Conceptual boundary confirmed; runtime not implemented`.

Minimum landing capabilities:

```text
ready
claimed / leased
blocked
review-needed
completed
rejected / retryable
timeout / recovery
canonical work state separated from notification
```

Carriers MUST NOT be pre-bound to Beads, GitHub Issues, Mailbox, or Markdown.

Status: `CONCEPT DEFINED` (taxonomy confirmed for conceptual scope; runtime not implemented).

---

## D. Software 3.0 / Protocol Governance

Current state: `Architectural responsibility defined; runtime not implemented`.

Minimum capabilities:

```text
protocol identity and version
scope
precedence
allowed / forbidden actions
human-approval boundary
validation / lint
change proposal
rollback
decision trace
```

Status: `CONCEPT DEFINED` (defined in doctrine; no operational runtime).

---

## E. AutoResearch / Experiment & Evaluation

Current state: `Method defined; operational loop not implemented`.

Minimum capabilities:

```text
fixed workload
baseline
candidate
independent evaluator
raw evidence
Keep / Refine / Discard / Revert verdict
no self-ratification by the executor
reproducible comparison
```

Status: `CONCEPT DEFINED` (method defined; no closed-loop runtime).

---

## F. Seed-Triggered Persistent Auto World

Current state: `Historical prototypes exist; reform runtime not implemented`.

Minimum safe form:

```text
Seed
→ bounded Work Item
→ one fresh executor instance
→ artifact output
→ external or protocol-governed review
→ stop
```

MUST NOT be enabled from the start:

```text
infinite loops
unbounded self-modification
automatic approval
unattended automatic dispatch
OpenClaw-style long-term autonomy
direct writes to the official Nexus
```

Status: `CONCEPT DEFINED` (historical prototypes exist; no reform runtime).

---

## G. Nexus Integration Boundary

Before entering the official Nexus, ALL of the following MUST hold:

```text
stable Artifact / Work Item contracts
Adapter boundaries
import / export
shadow replay
canonical truth not hijacked by legacy modules
outside verdict
rollback
official Nexus zero mutation before authorization
```

Legacy Nexus MAY be candidate-ized as:

```text
Letter Module
Inbox / Outbox Transport Adapter
Thread Projection Module
Archive Import Adapter
cc-connect Execution Bridge
Product / Domain Adapter
```

It is NOT decided in advance that all of these will be retained.

Status: `CONCEPT DEFINED` (boundary requirements defined; no shadow integration authorized).

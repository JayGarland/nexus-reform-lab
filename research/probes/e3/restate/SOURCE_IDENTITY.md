# SOURCE_IDENTITY.md — Probe source fixtures

Everything in this probe is generated by this probe. No official Nexus file,
verifier file, canonical state, Contract, Concept Model, Engine, or full Adapter
was created or modified. The only "source" is the disposable fixture service,
which is a thin test adapter driving Restate's native interface.

## FIXTURE/service (disposable test adapter)

```text
package.json          dependency: @restatedev/restate-sdk@1.16.2
package-lock.json     lockfile (reproducibility)
service.js            one virtual object "WorkItem" with native-only handlers
                      init, state, claim, startAttempt, runDurable, flaky,
                      touchWorkspace, finish
```

Handlers use only Restate native primitives:
- virtual object key serialization (per-key exclusive handlers) for claim atomicity
- ctx.set / ctx.get / ctx.getAll  (per-key K/V state)
- ctx.run  (durable journaled steps; exactly-once, retried)
- ctx.sleep (durable timers)
- idempotency via the `Idempotency-Key` ingress header
- ingress HTTP + admin API (PATCH pause/resume/kill, /query SQL)

The fixture intentionally does NOT implement a Work Item Engine (no ready/claim/
lease engine, no dependency resolver engine). Anything not expressible natively
is recorded as a GAP, never papered over.

## RAW_OUTPUT/query-tools/q.js

Disposable helper used to run SQL against the Restate `/query` service and decode
Arrow IPC; retained as evidence of the native query surface.
